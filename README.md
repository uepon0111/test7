# プロセカ リザルト画像リーダー

GitHub Pagesでそのまま公開できる、クライアントサイドHTMLアプリです。

## 構成
- `index.html` … UI
- `style.css` … UIスタイル
- `app.js` … 画像処理、位置検出、領域生成、2値化、OCR、デバッグ

## 使用方法
1. GitHub Pagesで公開したリポジトリの同じディレクトリに3ファイルを配置します。
2. 「画像を選択」またはドラッグ＆ドロップでリザルト画像を読み込みます。
3. 「位置検出 → OCR」で①〜⑰を一括実行します。
4. 「スキャン可視化」で取得した境界線を確認します。
5. 「A〜I領域」で処理前/処理後の画像とOCR結果を確認します。
6. 「デバッグ」でスキャン値・2値化統計・OCR詳細を確認できます。
7. 「デバッグJSON」で検出値を保存できます。

## OCRについて
OCRはTesseract.jsをCDNから読み込みます。そのため、初回OCR時にインターネット接続が必要です。画像そのものとOCR処理はブラウザ内で実行します。

## 補足
この初版は、提示されたスクリーンショットに合わせて「白枠→ジャケット→ゲージ→判定欄」の幾何構造を利用したロバストなヒューリスティック検出を実装しています。画像ごとの差が大きい場合は、`Debug > スキャン値` を確認し、閾値・最小連続長を調整してください。
