# プロセカ リザルト画像リーダー

GitHub Pagesで動作する、プロジェクトセカイのリザルト画面向け画像解析サンプルです。

## 主な機能
- Canvas上で入力画像を解析
- 指定された1〜10の走査方針をベースに、白枠・ジャケット・ゲージ・難易度・レベル・判定行・スコア列・LATE/FAST境界を自動推定
- A〜I領域を自動切り出し
- 各領域をグレースケール＋局所二値化してOCR
- 楽曲タイトル、難易度、楽曲レベル、PERFECT/GREAT/GOOD/BAD/MISS、COMBOを表示
- 各領域の処理前／処理後画像を表示
- 走査プロファイル、候補位置、OCR原文、検出結果をデバッグ表示
- デバッグJSON保存

## 起動
GitHub Pagesへ配置するだけで動作します。OCRはTesseract.jsとCDN上の学習データを使用します。

## 注意
スクリーンショットのテーマ・解像度・UI変更によって境界検出が外れる可能性があります。本実装は、提示されたリザルト画面のレイアウトを基準に、複数サンプルの走査・中央値・候補位置のフォールバックを組み合わせています。実運用では複数端末・複数解像度で閾値を追加調整してください。
